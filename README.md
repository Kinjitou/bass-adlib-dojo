# ベース・アドリブ道場

ベース初心者が、楽器を持ったまま直感的にアドリブを覚えるための Web アプリです。

## 機能

- **レッスン**：ルート → 5度 → マイナー・ペンタ → ブルーノート → メジャー・ペンタ → コードトーン → リズム → 丸サ進行の 8 ステップ
- **スケール**：13 種類のスケール／アルペジオを指板上に色分け表示（R・3度・5度・7度・♭5）
- **進行モード**：7 種類の進行に合わせて、いま鳴っているコードの構成音と次のコードのルートを指板にリアルタイム表示
- **伴奏**：ドラム＋コードを Web Audio で再生（ベースパートは鳴らさない）。テンポ・音量調整あり
- **スマホ対応**：画面幅 700px 以下では縦向きの指板と、画面下の固定コントロールバーに切り替わる

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドや外部依存はありません（フォントのみ Google Fonts を利用）。

## 注意

- 伴奏はブラウザ内の合成音です。iPhone はマナーモードだと鳴らない場合があります。
- 設定（キー・レッスンの進み具合など）はブラウザの localStorage に保存されます。
