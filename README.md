# ベース・アドリブ道場

ベース初心者が、楽器を持ったまま直感的にアドリブを覚えるための Web アプリです。

## 機能

- **レッスン**：ルート → 5度 → マイナー・ペンタ → ブルーノート → メジャー・ペンタ → コードトーン → リズム → 丸サ進行の 8 ステップ
- **スケール**：15 種類のスケール／アルペジオを指板上に色分け表示（R・3度・5度・7度・♭5）
- **進行モード**：7 種類の定番進行に合わせて、いま鳴っているコードの構成音と次のコードのルートを指板にリアルタイム表示
- **セッション**：好きなコードを最大 16 小節まで入力してループ再生（1 小節に 2 コードまで）。ボタン入力とテキスト入力（例：`Am7 | D7 | Gmaj7 Cmaj7`）、移調、定番進行の読み込みに対応
- **クロマチック**：初級・中級・上級のプリセット付き運指トレーニング
  - パターン：1-2-3-4 往復／指順の入れ替え（1-3-2-4 など 6 種）／弦飛ばし／スパイダー
  - 4 分・8 分・3 連・16 分、テンポ 40〜200 BPM
  - 1 周ごとのポジション移動、自動テンポアップ（上げ幅・間隔・上限を指定）
  - 指板上に「いま弾く音」と「次の音」、押さえる指の番号を表示
- **伴奏**：ドラム＋コードを Web Audio で合成して再生（ベースパートは鳴らさない）
  - リズム：8ビート／ミニマル・ファンク（Vulfpeck風）／16ビート（シティポップ）／ハーフタイム・シャッフル／ディスコ／ボサノバ
  - コード楽器：パッド／エレピ／クラビ（リズムに合わせた自動選択あり）
- **スマホ対応**：画面幅 700px 以下では縦向きの指板と、画面下の固定コントロールバーに切り替わる

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドや外部依存はありません（フォントのみ Google Fonts を利用）。

## 注意

- 伴奏はブラウザ内の合成音です。iPhone はマナーモードだと鳴らない場合があります。
- 設定（キー・レッスンの進み具合・入力したコード進行など）はブラウザの localStorage に保存されます。
